NumPy

Numerical Python — fast math on grids of numbers

What it actually is

NumPy gives Python a new data container called an array — a grid that holds only numbers, all of the same type. Because every slot is identical, NumPy can do math on the entire grid at once, using code written in C under the hood — which makes it dramatically faster than a normal Python list.

Real-world analogy

A NumPy array is a muffin tray. Every slot is exactly the same size and holds the same kind of thing. Want to add one chocolate chip to every muffin? You do it to the whole tray in one move — you don't visit each slot separately. That's what arr + 1 does to every number in an array.

Where it's used

Machine learning (behind pandas & scikit-learn) Image processing (an image is a grid of pixel numbers) Scientific & engineering calculations Finance & simulations
Core types
1D array

A single row of numbers: [4, 8, 15]. Like one line of a muffin tray.

2D array

Rows & columns, like a full spreadsheet grid: [[1,2],[3,4]].

3D+ array

A stack of grids — e.g. a color photo (height × width × RGB).

Syntax & methods — click Run to see the output
In [1]:
import numpy as np

# create an array from a list
arr = np.array([4, 8, 15, 16])
print(arr.shape)
Out[1]:
(4,)  # 4 numbers, in one row
In [2]:
# do math on the WHOLE array at once — no loop needed
prices = np.array([100, 250, 80])
discounted = prices * 0.9   # 10% off, every item
print(discounted)
Out[2]:
[90. 225. 72.]
In [3]:
# build arrays without typing every number
grid = np.zeros((2, 3))       # 2 rows, 3 columns, all 0
steps = np.arange(0, 10, 2)   # start, stop, step
print(grid)
print(steps)
Out[3]:
[[0. 0. 0.] [0. 0. 0.]] [0 2 4 6 8]
In [4]:
# quick stats — no loop needed
scores = np.array([72, 88, 91, 60])
print("mean:", scores.mean(), "| max:", scores.max())
Out[4]:
mean: 77.75 | max: 91
Fresher tip: if you're doing math on a list of numbers and reaching for a for loop, stop — that's almost always a sign you want a NumPy array instead.
💡
Good to know: "NumPy" is short for Numerical Python. It was first released in 2006, and its array object (ndarray) is the shared foundation that Pandas, Matplotlib, and most machine-learning libraries are built on top of — learning it well makes the other three easier.
QUICK CHECK

Why is a NumPy array faster than a plain Python list for math?

ANSWER

Because every element is the same fixed type, so NumPy can run the operation on the whole block of memory at once, in optimized C code, instead of Python checking each item one by one.

pd

Pandas

Labeled tables for organizing & analyzing data

What it actually is

Pandas is built on top of NumPy and adds labels — row names and column names — to your data, so instead of a nameless grid of numbers, you get a table you can query by name, just like a spreadsheet, but scriptable and repeatable.

Real-world analogy

A pandas DataFrame is your class attendance register. Each row is one student, each column is a subject, and every cell is clearly labeled — so you always know "Rahul's Math score" instantly, instead of counting rows and columns by hand.

Where it's used

Cleaning messy datasets Reading CSV / Excel files Business & sales reporting Preparing data for ML models
Core types
Series

One labeled column — a single subject's marks for every student.

DataFrame

The full table — rows × columns, like the whole register.

Index

The row labels — e.g. student roll numbers or names.

df = pd.DataFrame(data)
df.head()

Fresher tip: real data is messy. df.isna().sum() tells you how many blanks are hiding in each column before you trust any analysis.
Cleaning data — handling empty cells 🧹 Very common in interviews

Real datasets almost always have missing values — an empty mark, a blank name. Left alone, empty cells can quietly skew an average or break a calculation. Pandas gives you a few simple methods to find and handle them, shown individually below.

isna()

Checks every cell and returns True where a value is missing. Almost always paired with .sum() to count blanks per column — the first thing to check before trusting any analysis.

Syntax
DataFrame.isna()
In [5]:
print(df.isna().sum())   # how many blanks per column?
Out[5]:
name 0 marks 1 dtype: int64
dropna()

Removes rows that contain at least one empty cell, and returns a brand-new DataFrame. This is usually safe when your dataset is large — losing a handful of rows out of thousands rarely changes the result much.

Syntax
DataFrame.dropna()
In [6]:
# returns a NEW DataFrame with the empty-cell rows removed
clean_df = df.dropna()
print(clean_df)
Out[6]:
name marks 0 Asha 88.0 2 Meera 95.0
Note: by default dropna() does not touch the original df — it hands you a new, cleaned copy. If you want the original DataFrame itself to change, add inplace=True, as shown next.
dropna(inplace=True)

Same job as dropna(), except it edits the original DataFrame directly instead of returning a copy — there's nothing to reassign afterwards.

Syntax
DataFrame.dropna(inplace=True)
In [7]:
df.dropna(inplace=True)  # changes df itself, returns None
print(df)
Out[7]:
name marks 0 Asha 88.0 2 Meera 95.0
Note: with inplace=True, the method returns None — don't write df = df.dropna(inplace=True), or you'll accidentally wipe out df entirely.
fillna()

Instead of deleting rows, this fills every empty cell with a value you choose — useful when you can't afford to lose rows, e.g. replacing a missing mark with the class average.

Syntax
DataFrame.fillna(value)
In [8]:
avg = df["marks"].mean()
df["marks"] = df["marks"].fillna(avg)   # fill blanks with the average
print(df)
Out[8]:
name marks 0 Asha 88.0 1 Ravi 85.0 2 Meera 95.0
drop_duplicates()

Removes rows that are exact repeats of an earlier row — handy when the same record accidentally got entered twice (e.g. a student submitted the same form twice).

Syntax
DataFrame.drop_duplicates()
In [9]:
df.drop_duplicates(inplace=True)
print(df)
Out[9]:
name marks 0 Asha 88.0 1 Ravi 85.0 2 Meera 95.0
💡
Good to know: the name "Pandas" comes from "Panel Data", an econometrics term for datasets that track many subjects over multiple time periods — exactly the kind of table Pandas was built to handle.
QUICK CHECK

What's the difference between df.loc[] and df.iloc[]?

ANSWER

.loc selects by label/name (e.g. row named "Asha"), .iloc selects by numeric position (e.g. the 1st row), no matter what the labels are.

Matplotlib

The foundational library for drawing charts

What it actually is

Matplotlib turns numbers into pictures — line graphs, bar charts, scatter plots. It's low-level and extremely flexible: you control every line, color, and label yourself. Almost every other Python plotting library (including Seaborn) is built on top of it.

Real-world analogy

Matplotlib is a blank canvas and a full box of drawing tools. Nothing is decided for you — you choose the axes, the colors, the title. Powerful, but you do the styling work yourself.

Where it's used

Exploring trends in data Reports & dashboards Scientific papers & research plots
Setup — do this once
import matplotlib.pyplot as plt
Chart types — definition, syntax & example for each 📊 click Run on every one
Line Plot

Definition: a line plot connects data points with a straight line, in the order they're given. It's the standard chart for showing how a value changes over time or over a sequence — e.g. temperature across a week, or a stock price across a month.

Syntax
plt.plot(x, y)
plt.show()
In [1]:
days = ["Mon","Tue","Wed","Thu","Fri"]
temp = [28, 30, 27, 31, 29]

plt.plot(days, temp, marker="o")
plt.xlabel("Day"); plt.ylabel("°C")
plt.title("Weekly Temperature")
plt.show()
Out[1]:
Bar Chart

Definition: a bar chart uses rectangular bars to compare a value across separate categories. Longer bar = bigger value. Use it when your x-axis is a set of names, not a continuous scale.

Syntax
plt.bar(categories, values)
plt.show()
In [2]:
cities = ["Pune", "Delhi", "Kochi"]
revenue = [500, 150, 260]

plt.bar(cities, revenue, color="#E4572E")
plt.title("Revenue by City")
plt.show()
Out[2]:
Scatter Plot

Definition: a scatter plot places one dot per data point using two numeric values (x and y). It's the go-to chart for spotting a relationship or pattern between two variables — e.g. does studying more hours relate to higher marks?

Syntax
plt.scatter(x, y)
plt.show()
In [3]:
study_hrs = [1, 2, 3, 4, 5, 6, 7, 8]
marks     = [40, 48, 46, 60, 65, 72, 80, 90]

plt.scatter(study_hrs, marks, color="#E4572E")
plt.xlabel("Hours studied"); plt.ylabel("Marks")
plt.show()
Out[3]:
Histogram

Definition: a histogram groups numbers into ranges ("bins") and shows how many values fall in each range as bars. Unlike a bar chart, it's for one numeric column, and it reveals the distribution — e.g. how marks are spread across a class.

Syntax
plt.hist(data, bins=5)
plt.show()
In [4]:
marks = [45, 52, 58, 60, 63, 67, 70, 75, 82, 91]

plt.hist(marks, bins=5, color="#E4572E")
plt.xlabel("Marks range"); plt.ylabel("Number of students")
plt.show()
Out[4]:
Pie Chart

Definition: a pie chart splits a circle into slices, where each slice's size shows its share of a whole (percentages that add up to 100%). Best for a small number of categories — 3 to 6 — beyond that it gets hard to read.

Syntax
plt.pie(values, labels=names, autopct='%1.0f%%')
plt.show()
In [5]:
subjects = ["Math", "Science", "English"]
hours    = [5, 3, 2]

plt.pie(hours, labels=subjects, autopct='%1.0f%%')
plt.show()
Out[5]:
Fresher tip: always call plt.show() (or just let the last line of a notebook cell display the plot) — otherwise your chart may never actually appear.
💡
Good to know: Matplotlib was created by John D. Hunter in 2003 while he was analyzing brain-signal (EEG) data and wanted a free, Python-based alternative to MATLAB's plotting tools.

sns

Seaborn

Beautiful statistical charts, built on Matplotlib

What it actually is

Seaborn sits on top of Matplotlib and adds smart defaults made for statistics: it understands pandas DataFrames directly, picks good colors automatically, and can compute things like averages and confidence intervals for you as it plots.

Real-world analogy

If Matplotlib is a blank canvas and paintbrush, Seaborn is an interior designer who walks into that same room and instantly makes it look professionally styled — using sensible defaults instead of asking you to choose everything.

Where it's used

Exploring relationships between variables Correlation heatmaps Comparing distributions across groups
Setup — do this once
import seaborn as sns
Chart types — definition, syntax & example for each ✨ styled automatically
Scatter Plot

Definition: same idea as Matplotlib's scatter plot — one dot per data point — except it reads column names straight from a DataFrame, and hue can auto-color the dots by a third category, like "passed / failed", for free.

Syntax
sns.scatterplot(data=df, x="col1", y="col2", hue="category")
In [1]:
# works directly with a DataFrame — just name the columns
sns.scatterplot(data=df, x="study_hrs", y="marks", hue="passed")
Out[1]:
Heatmap

Definition: a heatmap colors every cell of a grid of numbers based on its value — darker or brighter usually means a bigger number. It's most often used to visualize a correlation matrix, so you can spot which columns move together at a glance.

Syntax
sns.heatmap(data, annot=True, cmap="Purples")
In [2]:
# darker = stronger relationship
sns.heatmap(df.corr(), annot=True, cmap="Purples")
Out[2]:
Box Plot

Definition: a box plot summarizes a group of numbers in one shape: the box covers the middle 50% of values, the line inside is the median, and the "whiskers" extend to the typical range — dots beyond them are outliers. Great for comparing spread across groups.

Syntax
sns.boxplot(data=df, x="category", y="value")
In [3]:
# compare spread of marks across two sections
sns.boxplot(data=df, x="section", y="marks")
Out[3]:
Violin Plot

Definition: a mix of a box plot and a distribution curve — the width of the "violin" at each height shows how many values sit around there. It shows everything a box plot does, plus the actual shape of the spread.

Syntax
sns.violinplot(data=df, x="category", y="value")
In [4]:
sns.violinplot(data=df, x="section", y="marks")
Out[4]:
Count Plot

Definition: automatically counts how many rows fall into each category and draws a bar for each — you don't even need to calculate the counts yourself first, unlike a normal bar chart.

Syntax
sns.countplot(data=df, x="category")
In [5]:
# counts rows per section automatically
sns.countplot(data=df, x="section")
Out[5]:
Pair Plot

Definition: automatically plots every numeric column in a DataFrame against every other one, arranged in a grid — a fast way to scan an entire dataset for relationships in a single command, without writing a chart for each pair yourself.

Syntax
sns.pairplot(df)
In [6]:
sns.pairplot(df)
plt.tight_layout(pad=2.0)  # stops axis labels getting cut off at the edges
plt.show()
Out[6]:
Note: if a chart's bottom or right-hand labels look cramped or clipped, that's almost always a spacing issue, not a data issue. Call plt.tight_layout(pad=2.0) right before plt.show(), or pass bbox_inches='tight' to plt.savefig() when exporting a chart to a file — both re-fit the figure so every axis label stays fully visible.
Fresher tip: if your x-axis / y-axis are column names from a DataFrame, reach for Seaborn first — it usually takes one line where Matplotlib would take five.
💡
Good to know: Seaborn is named after Sam Seaborn, a character from the TV show The West Wing — a small nod from its creator, Michael Waskom.
QUICK CHECK

Is Seaborn a replacement for Matplotlib, or built on it?

ANSWER

Built on it. Seaborn generates Matplotlib figures underneath — you can still use Matplotlib functions like plt.title() to customize a Seaborn plot.
